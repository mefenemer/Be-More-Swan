Why this is a designed screen and not a “coming soon” badge. A control that renders, promises and can never return a value is a bug we have shipped before — a follower metric with no scope behind it, a top-up button with no purchase flow. Naming the specific blocker per platform is the difference between a roadmap and a lie.

Why this state exists at all. Connections in this product have died silently before and kept a green “Connected” badge while doing nothing — and a five-second database blip has destroyed a rotating token outright. On every other assistant that costs you some missed posts. Here it means money moving that we cannot stop, so it gets its own state, its own words, and a route out that does not depend on us.
The matching rule on the way back. Every pause has a named resume. “Stop everything” writes down what it stopped and why, and each stopped campaign lists its own way back on this tab — the last time we shipped a pause without one, paused posts and suspended assistants sat there for weeks and nobody noticed.
