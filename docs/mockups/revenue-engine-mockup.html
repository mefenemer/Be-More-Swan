Why DM can't use this screen

A signal arriving 18:00 Friday expires 18:00 Saturday. Approve it Monday and the reply cannot be sent at all — not late, impossible. The prospect is left on read.
So per-message review is descoped for DM. Instead:
Class CPre-approved reply set, reviewed once and versioned
Class AIndividual sends inside that set — ungated
⏱Escalating nudge at 50% / 80% of window
↩Window closed → fall back to email if an address is known
